# nib Health Cover

Static HTML/CSS recreation of the nib health insurance site, built as a front-end
web development training exercise.

## Pages

- `index.html` — homepage
- `singles-health-cover.html` — singles health cover
- `hospital-extra-cover.html` — hospital & extras cover

## Running locally

```
python3 -m http.server 8000
```

Then open http://localhost:8000

## Notes

All asset paths are document-relative so the site works both locally and when
served from a GitHub Pages project subpath.
